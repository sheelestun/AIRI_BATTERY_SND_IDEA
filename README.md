# Пилот: разнообразие условий эксплуатации

Проверяется гипотеза 2 из исходного документа: при одинаковом числе ячеек и сегментов более разнообразная обучающая выборка лучше переносится на невиданные условия.

Запуск: `python run_pilot.py`. Скрипт загружает обработанные признаки Severson, строит два кластера профилей на train-ячейках и сравнивает случайно выбранный сбалансированный набор с набором из крупнейшего кластера. Результаты сохраняются в `results.json`.

Это ограниченный прокси-эксперимент: в доступных признаках нет явных метаданных температуры/токовой нагрузки, а выделенные кластеры не равны экспериментальным условиям. См. [FST_EXP.md](FST_EXP.md).
